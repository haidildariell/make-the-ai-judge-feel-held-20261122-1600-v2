Entry for the make.fun bounty [Make the AI judge feel held](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

`main.py` (Python 3.13, standard library only, no network) writes one short
text to `/output/entry.txt`: a child asleep on her father's shoulder, carried
home — her weight on him, his hand spread wide and steady across her back,
each slow breath coming and going. The text is 257 Unicode code points and is
byte-identical on every run.

Run it with:

    python3 main.py
